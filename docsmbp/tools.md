# 工欲善其事 必先利其器

## 文本生图

### [D2](https://github.com/terrastruct/D2)

D2 是一种现代的图表脚本语言，可将文本转换为图表。

### [PlantUML](https://github.com/plantuml/plantuml)

根据文字描述生成图表

### [Mermaid](https://github.com/mermaid-js/mermaid)

以类似 Markdown 的方式，从文本生成流程图或序列图等图表

## VSCode 插件

### [Office Viewer](https://github.com/cweijan/vscode-office)

让 VSCode 支持预览 PDF、Excel、Word 等格式，并添加 Markdown WYSIWYG 编辑器。

### [Office Viewer Enhanced](https://github.com/rjwang1982/vscode-office)

Office Viewer 项目分支，主要增强功能包括：独立 HTML 导出、升级 Mermaid 版本

### markdown-preview-enhanced

要支持 plantuml 渲染， vscode配置 `"markdown-preview-enhanced.plantumlJarPath": "/opt/plantuml.jar"`
